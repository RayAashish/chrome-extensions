Security & Header Modifications Transparency

To embed localhost pages inside iframes without X-Frame-Options or Content-Security-Policy: frame-ancestors errors, this extension uses Chrome's declarativeNetRequest session rules.

  • Scoped strictly to localhost: Rules only match requests to localhost, 127.0.0.1, [::1], and *.localhost.
  • Sub-frame only: Headers are never modified on top-level tabs or internet sites.
  • Session-only: Rules are automatically erased by Chrome upon browser shutdown and cleaned up when workspaces close.
  • Zero Cloud Telemetry: Runs 100% locally on your machine with zero third-party network requests.
